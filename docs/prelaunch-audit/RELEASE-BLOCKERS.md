1. **Close the Critical report-RPC tenant leak.** Production grants `PUBLIC`, `anon`, and `authenticated` direct execute access to nine SECURITY DEFINER report functions that accept a caller-supplied portfolio UUID. The forward execution-boundary migration revokes this access, but it is not applied or staging-tested. Verify anon/authenticated denial and server-side service-role success across two audit portfolios. **Scope: small code change, high-risk validation.**
2. **Reconcile migration history.** Strict validation fails with 41 invalid filenames and three duplicate-version groups. Inventory linked production history, preserve applied SQL, create a reviewed forward-only baseline, and require explicit database-owner review before any `migration repair`. Do not rename or reorder applied migrations casually.
3. **Make staging reproducible.** The staging project `zalfkrtjeswvfmucicea` is linked but empty. A dry run cannot authenticate in the current audit environment because no reusable Supabase token/database password is available. No migration was applied.
4. **Complete all report implementations.** The deployed catalog exposes 119 reports. Eighteen slugs have live page implementations and the production dispatcher supports only eight queued report families; every other queued slug raises `not implemented`. The nine report functions are absent from local migration SQL. Recover the authoritative SQL, add reviewed forward migrations, and require scope/permission/data/export tests for every catalog slug. **Scope: large.**
5. **Complete authenticated report execution.** Trial Balance live display and export code are corrected and CI/deployment-clean, but the new preview hostname lacks a manager login session. Replay duplicate, reordered, and concurrent Stripe test-mode webhooks for two associations with distinct connected accounts.
7. **Prove role and tenant isolation.** Run Platform Operator, Company Admin, Manager, Board, Owner, and Vendor workflows against two associations. Include forged IDs, direct URLs, cross-association storage paths, server actions, and service-role boundaries.
8. **Validate external provider and operations gates.** Confirm Preview uses staging Supabase and Stripe test mode, then verify Plaid, Resend, scheduled jobs, backups/restores, alerts, and all required environment variables without exposing secrets.


# Release blockers

1. **Reconcile migration history and prove a clean replay (large).** Production reports 159 applied migration statements while the repository has invalid filenames, duplicate version groups, and missing remote versions. Fetch exact remote history into a clean checkout, preserve applied SQL, produce a forward-only plan, replay into empty staging, and require an owner-approved diff before production.
2. **Apply and verify the database execution boundary (large).** Production currently exposes 151 SECURITY DEFINER functions to `anon` and `authenticated`, including all report-data helpers. Apply the hardening migrations in staging, run the full role/RLS matrix, then deploy through the approved production process.
3. **Implement accountant-approved payment-to-GL posting (architectural).** Manual and Stripe receipts update the receivable subledger without transaction-level GL entries. Implement an atomic source-linked Cash/Clearing-to-A/R design and prove duplicate, failure, refund, and reversal behavior.
4. **Make all 119 advertised reports truthful (large).** Ninety-five catalog entries have no live implementation or supported dispatcher. Implement each report with association/company scope and accounting tie-outs, or visibly mark it unavailable without deleting it. Verify every export format.
5. **Complete per-association Stripe test onboarding (medium).** Zero of two active associations have connected accounts. Complete test-mode Connect onboarding for each staging association and verify scoping, fees, webhook signature/idempotency, failure, refund, payout, and reconciliation.
6. **Seed and execute full staging role workflows (large).** Staging is empty and cannot be safely seeded until migration history replays. Then create the marked reversible fixture and test Platform Operator, Company Admin, Manager A/B, Board, Owner, Tenant, and Vendor through UI, endpoints, RLS, storage, and direct-ID tampering.
7. **Prove Plaid and reconciliation behavior (large).** Production contains no Plaid items, bank transactions, or reconciliations. Exercise unmatched, partial, exact, duplicate, failed-worker, and manual-match cases in staging and tie them to journal/bank balances.
8. **Complete production configuration, recovery, and operational gates (medium).** Validate required environment values without printing secrets; verify cron authentication, monitoring, backup restoration, rollback, rate limits, and notification suppression in staging.
